# Reviews

This folder contains project-specific technical review artifacts.

Each review should correspond to a story implementation or a meaningful technical checkpoint.

## File naming

Use stable names:

- STORY-001-code-review.md
- STORY-002-code-review.md

## Review rules

A review must include:

- story ID
- implementation evidence
- acceptance criteria review
- architecture alignment
- findings
- decision
- required changes when failed
- next owner

## Gate rule

BroQA should not perform final functional validation before BroReview passes, unless BroMaster explicitly records a gate override.
